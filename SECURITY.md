# Security

> [!IMPORTANT]
> Please only report vulnerabilities related to the GitOps Operator.
> For vulnerabilities found in its operands (Argo CD, Redis, Argo Rollouts, etc.), report them to the respective communities.

## Reporting a Vulnerability

For security related issues in the GitOps Operator, please [Report a Vulnerability] through our dedicated form.
All vulnerabilities and associated information will be treated with full confidentiality.
Once reported, please be available for communication with repository maintainers, and allow us appropriate time to respond.


## Public Disclosure

Security vulnerabilities will be disclosed via [GitOps Operator release notes].

[Report a Vulnerability]: https://github.com/redhat-developer/gitops-operator/security/advisories
[GitOps Operator release notes]: https://docs.redhat.com/en/documentation/red_hat_openshift_gitops
